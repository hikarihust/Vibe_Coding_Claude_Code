# AI Coding's Chatbot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web app chat cá nhân với Ollama `gemma4:31b-cloud`, streaming câu trả lời, lưu session vào SQLite, sidebar quản lý session (new / rename / delete), light/dark mode, responsive.

**Architecture:** FastAPI backend (`backend/`) với 3 module: `db.py` (sqlite3 thuần), `llm.py` (stream từ Ollama), `main.py` (routes, `create_app(db_path)` factory). Endpoint gửi tin nhắn trả `StreamingResponse` text/plain. Frontend React + Vite (`frontend/`) gọi `/api` qua Vite proxy, đọc stream bằng `fetch` + `ReadableStream`, state nằm trong `App.tsx`.

**Tech Stack:** Python 3.13, FastAPI, uvicorn, `ollama` (AsyncClient), sqlite3, pytest. Node 26, Vite (template react-ts), Tailwind CSS v4 (`@tailwindcss/vite`), react-markdown, remark-gfm, rehype-highlight, highlight.js.

**Spec:** `docs/superpowers/specs/2026-11-22-chatbot-design.md`

## Global Constraints

- Model: `gemma4:31b-cloud`; Ollama host mặc định `http://localhost:11434`; không system prompt; gửi toàn bộ lịch sử, không cắt.
- Tiêu đề app: `AI Coding's Chatbot`.
- Tên session = prompt đầu tiên, gộp khoảng trắng liên tiếp thành 1 dấu cách, trim, lấy 20 ký tự đầu. Không thêm "…" vào dữ liệu.
- "New Chat" không ghi gì vào DB; session chỉ được tạo khi gửi tin nhắn đầu tiên.
- Câu trả lời dở dang (lỗi / huỷ) không bao giờ được lưu. Tin nhắn user luôn được lưu trước khi gọi Ollama.
- Màu (từ `design-system-DESIGN.md`): brand `#6c4cf2` / hover `#5638d6` / `#4229ad`; neutral `#ffffff #f7f7f8 #ededf0 #dfe0e4 #c5c6cc #a0a3ac #71737c #5b5f68 #17181b`; danger `#e5484d` / `#cc3b37`, danger-100 `#fde2e1`. Font Inter (chữ), JetBrains Mono (code). Lưới khoảng cách 4px/8px.
- Theme: mặc định **light**; người dùng chuyển light/dark; lựa chọn lưu ở `localStorage` key `theme`. (Spec mục 2 thắng câu "Chỉ giao diện sáng" ở 5.5.)
- Responsive (diễn giải của Claude, vì spec vừa có "responsive" vừa có non-goal "tối ưu cho mobile"): ≥ `md` (768px) sidebar cố định rộng 256px; < `md` sidebar ẩn, mở thành ngăn kéo phủ lên qua nút ☰ ở header. Không làm gì thêm cho mobile.
- Mọi lệnh Python chạy trong `backend/.venv` (Windows: `backend/.venv/Scripts/python`).

## Review Focus

1. **Đổi session / New Chat khi đang stream** — chữ đến muộn không được ghi vào session mới mở, và việc huỷ không hiện thành lỗi. → kiểm tra thủ công ở Task 6, Step 6.
2. **Ollama chưa chạy / chưa signin** — trả 502 với thông báo dễ hiểu, tin nhắn user vẫn còn khi reload. → `test_ollama_down_returns_502_and_keeps_user_message` (Task 3).
3. **Tiếng Việt có dấu** — tiêu đề cắt theo ký tự (không vỡ dấu), và stream không vỡ ký tự nhiều byte ở ranh giới chunk (`TextDecoder` với `{stream: true}`). → `test_make_title_vietnamese` (Task 1), `test_stream_vietnamese_roundtrip` (Task 3).
4. **Gõ tiếng Việt bằng bộ gõ (IME/Telex)** — nhấn Enter để chốt chữ trong lúc composing không được gửi tin nhắn. → `Composer` bỏ qua Enter khi `e.nativeEvent.isComposing`; kiểm tra thủ công ở Task 6, Step 6.
5. **Input chỉ toàn khoảng trắng / xuống dòng** — nút Send bị vô hiệu; backend trả 422 nếu bị gọi trực tiếp. → `test_blank_content_422` (Task 3), `test_blank_title_422` (Task 2).

### Task 3: Endpoint gửi tin nhắn có streaming

**Files:**
- Modify: `backend/app/main.py` (thêm route)
- Create: `backend/tests/test_chat_api.py`

**Interfaces:**
- Consumes: `db.add_message`, `db.list_messages`, `db.get_session`, `llm.stream_chat`, `MessageCreate` (Task 1–2).
- Produces: `POST /api/sessions/{id}/messages` body `{content}` → `StreamingResponse`, `media_type="text/plain; charset=utf-8"`.

Luồng (spec 5.3) — phần không tự suy ra được:
```python
# trong route
if session missing: 404
add_message(user, content)                      # lưu trước
history = [{"role": m["role"], "content": m["content"]} for m in list_messages(...)]
stream = llm.stream_chat(history)
try:
    first = await anext(stream)
except StopAsyncIteration:
    first = ""
except Exception:
    raise HTTPException(502, "Không kết nối được Ollama. Kiểm tra Ollama đang chạy và đã `ollama signin`.")

async def body():
    parts = [first]
    yield first
    async for chunk in stream:   # lỗi ở đây: để exception thoát ra → kết nối bị cắt, không lưu
        parts.append(chunk)
        yield chunk
    with db.connect(db_path) as conn:          # kết nối riêng, không dùng lại kết nối của request
        db.add_message(conn, session_id, "assistant", "".join(parts))
```
Client ngắt kết nối → generator bị huỷ trước dòng lưu → không lưu (không cần code thêm).

import pytest
from app import llm

def fake(chunks, fail_at=None, calls=None):
    async def _stream(messages):
        if calls is not None:
            calls.append(messages)
        for i, c in enumerate(chunks):
            if i == fail_at:
                raise RuntimeError("ollama down")
            yield c
        if fail_at == len(chunks):
            raise RuntimeError("ollama down")
    return _stream

def new_session(client):
    return client.post("/api/sessions", json={"first_message": "q"}).json()["id"]

def msgs(client, sid):
    return [(m["role"], m["content"]) for m in client.get(f"/api/sessions/{sid}/messages").json()]

def test_stream_saves_user_and_assistant(client, monkeypatch):
    calls = []
    monkeypatch.setattr(llm, "stream_chat", fake(["Xin ", "chào"], calls=calls))
    sid = new_session(client)
    r = client.post(f"/api/sessions/{sid}/messages", json={"content": "hi"})
    assert r.status_code == 200 and r.text == "Xin chào"
    assert r.headers["content-type"].startswith("text/plain")
    assert msgs(client, sid) == [("user", "hi"), ("assistant", "Xin chào")]
    assert calls[0] == [{"role": "user", "content": "hi"}]

def test_full_history_sent(client, monkeypatch):
    calls = []
    monkeypatch.setattr(llm, "stream_chat", fake(["a"], calls=calls))
    sid = new_session(client)
    client.post(f"/api/sessions/{sid}/messages", json={"content": "1"})
    client.post(f"/api/sessions/{sid}/messages", json={"content": "2"})
    assert [m["content"] for m in calls[1]] == ["1", "a", "2"]

def test_stream_vietnamese_roundtrip(client, monkeypatch):
    monkeypatch.setattr(llm, "stream_chat", fake(["Đây là ", "tiếng Việt 🙂"]))
    sid = new_session(client)
    assert client.post(f"/api/sessions/{sid}/messages", json={"content": "x"}).text == "Đây là tiếng Việt 🙂"

def test_ollama_down_returns_502_and_keeps_user_message(client, monkeypatch):
    monkeypatch.setattr(llm, "stream_chat", fake([], fail_at=0))
    sid = new_session(client)
    r = client.post(f"/api/sessions/{sid}/messages", json={"content": "hi"})
    assert r.status_code == 502 and "Ollama" in r.json()["detail"]
    assert msgs(client, sid) == [("user", "hi")]

def test_mid_stream_error_not_saved(client, monkeypatch):
    monkeypatch.setattr(llm, "stream_chat", fake(["part"], fail_at=1))
    sid = new_session(client)
    with pytest.raises(RuntimeError):
        client.post(f"/api/sessions/{sid}/messages", json={"content": "hi"})
    assert msgs(client, sid) == [("user", "hi")]

def test_send_updates_session_order(client, monkeypatch):
    monkeypatch.setattr(llm, "stream_chat", fake(["a"]))
    a = new_session(client)
    b = new_session(client)
    client.post(f"/api/sessions/{a}/messages", json={"content": "x"})
    assert [s["id"] for s in client.get("/api/sessions").json()] == [a, b]

def test_blank_content_422(client):
    sid = new_session(client)
    assert client.post(f"/api/sessions/{sid}/messages", json={"content": "  \n"}).status_code == 422

def test_send_to_missing_session_404(client):
    assert client.post("/api/sessions/999/messages", json={"content": "x"}).status_code == 404
